04 / THE VISION

Toward digital engineers
people can delegate to.

Software work spans people, records and code. Reliable delegation means carrying an assignment from a brief handoff to a verified result.

Our goal is for people to set direction, choose priorities and review outcomes, while agents recover context, coordinate dependencies and deliver the work. Four capabilities are central to that goal.

01 / CONTINUITY

Keep context current.

Reconcile boards, versioned documents, conversations and code. Check which decisions still apply, and revise the plan when new evidence arrives.

02 / INITIATIVE

Find and clarify the work.

Start from a brief handoff, identify open requirements and find the responsible colleagues. Ask with code or execution evidence, while keeping unrelated work out of scope.

03 / CONCURRENT PROGRESS

Keep work moving.

When an answer is deferred or a question is referred to someone else, advance other actionable work. Return to the pending thread and resolve the dependency within the available budget.

04 / PERSISTENCE

Track every requirement to delivery.

Keep each requirement in view through clarification, implementation and verification. Finish with a handoff that accurately records delivered behavior, test results and remaining issues.

SWE-CoWork measures progress toward this goal by linking distributed requirements to executable checks and tracing what reaches the final delivery.

THE BENCHMARK

Real code.
An organization to navigate.

Each assignment pairs a real upstream repository with an authored workplace history. Colleagues have defined responsibilities, bounded local knowledge and disclosure rules.

The agent starts with a brief handoff, reconciles records, asks colleagues, changes the code and checks its work. New evidence can send it back to an earlier step.
